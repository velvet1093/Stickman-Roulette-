# Sakura Hearts

A browser pixel life sim, published from the uploaded Sakura Hearts source.

## Play

Once GitHub Pages is enabled for **main / (root)** in repository Settings → Pages, the game will be available at:

https://velvet1093.github.io/Stickman-Roulette-/

Use arrow keys or WASD to move, Shift to run, and E or Space to interact. On mobile, drag to move and tap A to interact. Progress saves in this browser; this standalone deployment does not include cross-device cloud saves.

## Run locally

No build or dependencies are required. Open `index.html`, or run `python -m http.server 8000` from this directory. All art and audio are generated in JavaScript. The optional Google font has a built-in fallback.

Original source files are in `js/` and `css/`.
